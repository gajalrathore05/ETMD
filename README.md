A comprehensive Web-based Employee Task Management Dashboard (ETMD) built with **Django**, providing interactive employee task assignment, department tracking, task analytics & visualizations, and email notification support.

---

## 🌟 Key Features

- **🔐 Dual Authentication**: Separate login portals for Administrators and Employees.
- **👥 Employee Management**: Register, view, edit, and search employees along with designation and contact management.
- **🏢 Department Management**: Create, assign, search, edit, and organize company departments.
- **📋 Task Assignment & Tracking**: Assign tasks with due dates, priorities (Low/Medium/High), and categories (Work/Personal/Errands).
- **📊 Analytics & Visualizations**: Automatically generated data charts using `matplotlib`, `pandas`, and `wordcloud`:
  - Employee Task Distribution Bar Charts
  - Task Deadline Tracking Charts
  - Task Description Word Clouds
  - Task Completion Rate and Remaining Tasks Pie Charts
  - Employee Performance Trends
- **✉️ Email Notification System**: Automated emails sent via SMTP upon employee onboarding and task assignment.

## 🚀 Getting Started

### Prerequisites

- **Python 3.8+** installed on your system.
- `pip` package manager.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/ETMD.git
cd ETMD
```

### 2. Create a Virtual Environment

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure Environment Variables (Optional)

Copy `.env.example` to `.env` and set your credentials:

```bash
cp .env.example .env
```

### 5. Run Database Migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

### 6. Create Superuser (Admin)

```bash
python manage.py createsuperuser
```

### 7. Run Development Server

```bash
python manage.py runserver
```

Open your browser and navigate to `http://127.0.0.1:8000/`.

---

## 📊 Analytics Generation

The analytics charts located under `ETMDAPP/static/CHARTS/` are dynamically generated by `ETMDAPP/utils.py` using `matplotlib` and `pandas` whenever the admin task report view is requested.
